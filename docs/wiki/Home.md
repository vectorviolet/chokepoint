# Chokepoint

A 2D tower defense game built with [pygame-ce](https://github.com/pygame-community/pygame-ce):
defend a winding path through 25 rounds of escalating enemies, then keep going in endless mode.

**Play it:** [itch.io](https://umutcanekinci.itch.io/chokepoint) ·
[latest GitHub release](https://github.com/vectorviolet/chokepoint/releases/latest) (Windows, macOS, Linux)

## Stats reference

Every number in the game, generated from its config on each change:

- [Stats](Stats): the index and how to read the tables
- [Towers](Stats-Towers): price, range, damage and DPS per level
- [Enemies](Stats-Enemies): HP, speed, reward and damage, and how they scale per round
- [Waves](Stats-Waves): what each round sends
